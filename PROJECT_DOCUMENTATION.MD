# Project Documentation

## Project Overview

This project is a responsive food-themed webpage created using HTML and CSS. The website showcases famous food items from Chinese, Indian, and Italian cuisines. The objective of the project is to apply CSS concepts, including selectors, box model, display properties, concepts and responsive design.

The webpage was designed to be visually appealing, responsive, and user-friendly across different screen sizes.
